# Examples

| File | Description |
| --- | --- |
| `test.rest` | Public jsonplaceholder.typicode.com smoke test |
| `sample.rest` | Elasticsearch request examples |
| `sample_global.rest` | Elasticsearch examples using the global section |
| `data.sample.json` | Bulk data referenced by `sample.rest` |

The Elasticsearch examples expect a service on `http://localhost:9200`.
Run them with `<C-j>` or `:VrcQuery`.
